# V20.2.5 内部气口压缩与最终视觉复核

本规则适用于完整话轮内部存在明显纯气口、长停顿或无信息静音，但前后仍属于同一句或同一语义单元的情况。它不授权删除犹豫词、反应、语气、动作或任何有效发音。

## 内部气口可删条件

- 当前工作单或用户反馈明确允许压缩该内部停顿。
- 删除区间使用源原生帧的包含端点范围；禁止按近似秒数裁切。
- 预期文本强制对齐证明删除区内没有词、音素、呼吸表达或有意义瞬态。
- 删除区不得与受保护的有效语音帧重叠。
- 前句最后音节完整；删除开始至少晚于前词结束 3 个原生帧。
- 后句首词完整；保留至少 3 个原生帧首词前余量，且不得超过首词前 3 帧门禁。
- 后句若以 `但/但是/所以/然后/接着` 等连接词开头，前一段必须保留其真实语义前提。
- 实现方式是把同一源拆成删除区前后的两个单调帧区间；禁止冻结、补帧、变速、静音遮盖或用其他素材填回时长。
- 删除后时长自然变短，不触发历史时长补料；只有当前工作单明确要求下限时，才能补一段完整且语义相连的话轮。

计划必须携带 `internal_silence_compactions`，每项绑定：左右 segment ID、删除帧范围、源 SHA-256、对齐证据路径/哈希、前后词帧、受保护语音范围、用户授权来源和 `tokens_intersecting_deleted_range: []`。

## PCM 满幅峰值修复

- `PCM_CLIPPING_NEAR_BOUNDARY` 不能用删音、静音、交叉淡化或移动切点掩盖。
- 当台词与画面边界正确、仅源音量满幅时，可对同一原生帧区间制作一次均匀降幅派生源；增益必须 `0 < gain <= 1`，不得局部改变语气。
- 派生源必须保留原片帧血缘、增益值、源/派生 SHA-256，并重新跑 source boundary、fresh ASR、PCM 和最终切点检查。
- 只替换命中该峰值的依赖成片；其他成片保持原音。

## 最终片头视觉复核

- 计划阶段的视觉族标签不能单独授权发布。
- 最终 exact-60 成片必须提取每条开头至少 60 帧，哈希绑定到当前输出文件。
- 独立复核按真实场景、机位、服装、景别和连续源镜头确认 `opening_visual_family_id`。
- 同一首镜头视觉族最多 3 条；开头+第二段视觉组合最多 2 条。
- 相同开头帧集或近重复视觉不得通过改 candidate ID、文本或文件名拆成不同视觉族。
