# 整批成片尽可能多样化

多样性是整批计划的择优目标，不是固定复用上限。用户要三条就规划三条，要四五十条就规划完整批次。素材有限时允许复用；不能因为无法做到零重复而减少交付数量，也不能为凑不同开头使用不完整口播、坏切点或不连贯的组合。语义、画面、音频、字幕和包装检查照常执行。

## 选片顺序

1. 从全部原片寻找能独立引入主题的完整开场，包括原片中段中语义自足的句子。检查语境、首尾帧和切点；需要前文的承接句不能当开头。给开场标注经实际画面确认的 `opening_visual_family`，依据场景、服装、机位和景别归类，不能根据文件名编造不同场景。
2. 围绕这些开场建立多个**完整、连贯的成片候选方案**。分散卖点、内容路线、中段、相邻片段组合和结尾。在不影响口播逻辑时才改变顺序；不能为了排列组合任意打乱承接词、因果或指代关系。
3. 比较整批方案，首先减少开头重复，其次减少完整成片组合重复，再降低源片段覆盖重合、相邻组合、结尾及开场画面家族的重复。优先使用尚未覆盖的可用素材，避免把少数安全片段反复塞进所有成片。同一开头不可通过延长后文、微移帧界、改名或改候选 ID 伪装成不同开头。
4. 数量超过可用开场或组合时，均衡复用，尽量给同一开头搭配不同中段、内容路线和结尾。没有固定的单片段使用次数上限。要根据**可用且合格的候选**解释重复，不能把原片文件数当作开场容量。候选池不足时先继续寻找合法开场和组合；不能只提供一个方案，再据此声称素材无法多样化。
5. 返修淘汰片段后，从候选池排除对应源哈希和区间，重新比较整批计划。不要在修完单条后直接复制其开头到另外所有成片。包装可在现有素材允许范围内分散文字钉和 BGM，但换字幕样式、音乐、镜像或变速不能算作口播素材多样化。

## 批量选择命令

Codex 将完整候选方案写成 `options.json`，格式与帧计划相同：`schema: video-montage-autonomous-plan/v260929`，`outputs` 包含所有候选，每条 `plan_id` 唯一，`segments` 含真实源哈希、原生整数帧范围、帧率和准确口播。候选输出可添加 `opening_visual_family`。候选数量不必等于请求成片数；候选方案不能只有孤立片段。

```powershell
assets/dependencies/python/python.exe scripts/autonomous/scripts/autonomous_montage.py diversify-plan --job-dir <任务目录> --options <options.json> --plan <batch_plan.json>
```

程序验证候选来源与帧契约，按工作单请求数量生成选定计划，允许必要复用，并写 `reports/diversity_selection_round_N.json`。选定输出会重新分配唯一 `montage-xx` ID；报告记录候选 ID 对应关系和使用次数。算法采用贪心选择及最多三次整批改进，适用于四五十条，不穷举全部排列，也不声称找到了全局最优。候选池是 Codex 的语义选择结果；算法不理解口播逻辑，也不自动批准质量。

然后照常运行 `plan-evidence --plan <batch_plan.json>` 和 `approve-plan --review <JSON>`，重新审查选中片段与拼接点。即使没有使用批量选择命令，`plan-evidence` 也会生成 `reports/batch_diversity_round_N.json`，避免手工计划绕过整批比较。报告以 SHA-256 绑定计划；使用候选池时还绑定候选文件。修改计划或候选池后必须重新生成证据和审核。

## 报告与审核

报告逐对比较开场、完整组合、源区间覆盖、相邻片段和结尾。开场比较首段的前 3 秒源区间，并比较归一化口播；相同前 12 个字的长口播视为同开场，以识别延长同一开头。源区间小幅移动依然会被识别。跨文件相同口播也计入重复。画面家族由 Codex 看帧补充，程序不能自动识别重新编码或另机位拍摄的同场景；报告同时列出未标注家族的输出，Codex 必须补充实际画面判断。

`opening_repeat_pairs` 和 `duplicate_sequence_pairs` 是重复的成片对数，越低越好；覆盖比例相对于两条中素材覆盖较短的一条。报告的 `warnings` 提示重新检查可避免的重复，不是拒绝条件，不提供多样性合格分数。`capacity_note` 只解释给定候选池，不能证明所有原片都已用尽。

新的计划审核需增加非空 `diversity_reason`：说明可用开场如何分散、组合如何变化、仍复用哪些素材及原因，并结合报告和实际画面判断。例如“有三个可独立开场，三条分别使用；共用片尾因为其他召回句存在残音，中段卖点和片段顺序不同”。不能只写“通过”或把包装变化当作开场不同。

多样性报告会绑定到计划证据和最终完成回执，完成时重验哈希。已有旧审核和完成回执保留原契约，不事后改写为已执行新规则。
