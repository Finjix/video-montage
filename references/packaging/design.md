# AI 字幕包装设计

字幕审核后，Codex 查看口播、镜头和既有效果预览，为每条视频编写 `subtitle_design`。AI只根据内容、情绪、画面留白与节奏选择现成效果及合适的组合，不临时创作、生成或修改效果，也不制作新动画、花字、着色器或装饰素材。没有合适的效果时使用静态字幕。渲染器执行已有实现，不调用模型 API。

## 当前效果范围

仅保留三种主字体（W8、得意黑、方糖体）、既有冰1/冰2/火1花字，以及向上弹入、呐喊声波、冰雪飘动；可使用静态或短淡入。已移除新增的快速放大落稳、橙色放射、重复文字排版、火焰情绪字、双层标题、信息卡片及新增两种花字。不要制作或添加装饰卡片，也不要用任务透明图片重新引入这些效果。

`assets/packaging/design/catalog.json` 提供现有效果的 PNG 连续帧、WebP 动画、适用场景、强度、字体兼容性与参数说明。

现成效果只允许使用文档列明的控制项：核实文字、三种主字体、黄白配色、8/9/10号、布局与显示/入场时长；不提交自定义效果定义、资源路径、运动帧或着色器参数。效果库的扩充须由用户另行明确要求，包装任务不自动扩库。

## 审美判断

每条视频选一种主字体，普通字幕保持统一。字号只允许剪映校准的8、9、10号：普通字幕默认8号，游戏名和特别突出的文字用9或10号。黄色 `#FFDE00` 承担主叙述，白色 `#FFFFFF` 辅助或局部强调。核实真实游戏名，填写 `game_names`，所有游戏名使用完整花字；不能拆成跨字幕的半个名字。非游戏视频可填空列表。

普通黄白字幕统一使用已校准的剪映黑色描边40：文字缩放164%，从1920参考画布换算到1440成片后为12.3像素，不随8/9/10号或主字体改变。使用完整字形蒙版生成闭合描边，保留小数厚度与透明边缘。冰1/冰2/火1使用现成效果自带的描边、发光和层次，不附加普通字幕描边。

普通叙述以静态为主。开场、关键卖点和情绪句可用已有入场动画，避免连续强动画。不要给每条字幕加动画，也不要为了展示效果而重复字幕文字。根据留白、人物位置和已有信息选择布局，避免遮脸、遮嘴或挡住正在讲解的游戏信息。根据最终成片调整。

## 配置

沿用 `video-montage-packaging/v1`，每个 `outputs` 项保存已审核字幕文件及哈希，并填写：

```json
{
  "subtitle_design": {
    "subtitle_sha256": "实际审核后的字幕SHA-256",
    "font": "w8",
    "game_names": ["无尽冬日"],
    "game_flower": "ice2",
    "game_font_size": 9,
    "reason": "厚实字形适合口播，黄字为主，解释白字，游戏名冰字；关键短句入场后落稳。",
    "cues": [
      {"index": 1, "text": "来玩无尽冬日", "color": "yellow", "font_size": 8,
       "layout": {"x": 0.5, "y": 0.69, "max_width": 0.9},
       "entrance": {"effect": "bounce_up", "duration_ms": 250}},
      {"index": 2, "text": "轻松解压", "color": "white",
       "entrance": {"effect": "none"}}
    ]
  },
  "graphic_layers": []
}
```

`cues` 使用从1开始的字幕索引，按顺序覆盖全部已审核字幕，文字必须一致。游戏名花字范围自动补入快照。`spans` 支持同一句局部变色或已有花字，例如 `{"start":0,"end":2,"color":"white"}`；字符范围从0开始，结束不包含该字符。花字选项仅为 `ice1`、`ice2`、`fire1`，不能截断完整游戏名。

`layout.x/y` 为归一化中心坐标，默认 `.5/.69`；`max_width` 限制最大宽度，`layout.size` 已删除并拒绝读取。`cues.font_size` 默认8，`spans.font_size` 可指定局部9或10；`game_font_size` 默认9，仅允许9/10，完整游戏名必须保持同一字号。8/9/10号在1440宽画布上对应153/173/192像素，保留三种字体原有视觉补偿。长句按固定字号换行（最多两行），默认平衡两行长度，避免末行孤字；Codex可用 `cues.line_breaks: [7]` 指定在第7个字符后按语义换行，不能截断游戏名或花字。不缩小；仍放不下时须重新分句或调整布局/动画，不能拆开游戏名。动画预留运动空间，越出画布或进入 `protected_regions` 时拒绝方案。保护区格式为 `{"box":[左,上,右,下],"start_frame":0,"end_frame_exclusive":180}`，坐标归一化，帧使用未加速60 fps时间轴。

`entrance.effect` 可为 `none`、`fade`、`bounce_up`、`shout_wave`、`ice_drift`。非静态动画时长至少50毫秒，不得超过所属字幕区间的一半，保证稳定阅读。整词W8冰2使用完整校准着色与运动；其他字体或混排使用对应通用运动，并保留所选字形与配色。

`graphic_layers` 可省略或填空列表，非空装饰图层会被拒绝。原有包装接口的人名条、免责、BGM不属于新增装饰卡片，按用户请求及核实素材使用；用户不要文字钉时也应省略 `text_pins`。

## 审核和重烧

所有字幕及原有包装先在未加速时间轴合成，最终统一1.2倍速一次。取证覆盖连续入场帧、稳定阅读、字幕起止与原有叠加层同屏画面。增强字幕方案的最终审核要求 `design_pass: true` 与具体 `design_reason`，同时通过原有语义、音频、字幕和交付检查。

清单逐视频记录实际字体、剪映字号、实际像素字号、局部字号范围、花字、动画参数、布局、资源哈希。重烧保留选择，仅改时间时重新校验区间；改文字或条数后标记 `needs_design_review`，Codex 核对字范围、时长和布局，更新方案并移除标记后重新包装。所有包装配置必须提供逐输出 `subtitle_design` 和 `subtitle_txt`，旧配置无设计字段直接拒绝。曾用已删除效果的试验配置须清空 `graphic_layers`，将花字和动画改为当前支持的选项。

开发预览可使用 `tools/preview_packaging_design.py --catalog` 刷新既有动画预览。三种校准动画仍使用实验工具的0.95逐帧验收。
