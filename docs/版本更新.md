# 版本更新

## v260928 (2026-09-28)

`video-montage` 首次发布。本条目涵盖项目仓库建立以来的全部实现。

### 剪辑流程

- 将语义分析、帧级渲染、FFmpeg 编码和独立成片质检整合为一个 Codex 技能；内部组件分模块维护，由执行器按预检、初始化、语义审核、控制器交付和最终验证的顺序运行。
- 使用本地 Whisper 模型分析中文口播，建立来源、候选语句、人物身份、画面和语义关系证据；对完整批次执行候选容量、组合唯一性、内容连贯性及开头视觉族门禁。
- 以原始素材帧号和帧率制定、审核及渲染计划。来源素材与派生素材绑定原片 SHA-256 和原始帧区间；用户否定区间、候选边界、语义审核及计划锁定均有可追溯的任务证据。
- 使用随包帧渲染器和 FFmpeg 输出默认 H.264/AAC、1440×2560、60 fps 视频；对编码后的每个开头、拼接点和结尾重新检查画面、PCM、语音对齐与实际成片，独立审核通过后才允许交付。

### 运行与分发

- 随包提供 64 位 Windows Python 3.13.15、FFmpeg/FFprobe、完整 Whisper 模型、所需 Python 模块及可选 CUDA 推理 DLL；运行预检检查关键文件、模块、工具与模型。
- `install.cmd` 在临时副本中运行发布回归，通过后覆盖安装到 `%USERPROFILE%\video-montage`，在 Codex 的两个技能目录注册单一技能，并支持 `-PreflightOnly`。安装异常时恢复原安装和技能入口。
- `uninstall.cmd` 删除本项目安装目录及指向该安装的技能连接，保留其他同名入口。
- `package.cmd` 在 `release/` 生成版本命名 ZIP，解压后为 `video-montage-v260928` 目录；发布包排除任务结果、缓存、Git 数据及已有发布包。
- 安装与发布不生成包级哈希清单、`.manifests/`、`artifacts/` 或部署报告；剪辑任务自身的 SHA-256 来源证据和审核回执继续保留。

### 文档与验证

- README、技能工作流和现行语义合同说明安装、执行、帧级约束及交付门禁；依赖版本单独列出，版本更新集中记录于本文件。
- 发布回归覆盖语义模块、控制器、执行器、安装与卸载、干净打包、文档链接及任务证据防篡改检查。
