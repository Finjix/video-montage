# 版本更新

## v260928 (2026-09-28)

### 主要变化

- 将语义分析、逐帧渲染和 FFmpeg 控制器整合为一个 Codex 技能 `video-montage`；内部组件仍分模块维护。
- 安装入口由 `start.cmd` 改为 `install.cmd`。安装前检查随包依赖与关键脚本，并在临时副本中运行发布回归；支持 `-PreflightOnly`。默认安装目录改为 `%USERPROFILE%\video-montage`，覆盖安装会清空该目录，并清理指向旧安装的三个技能入口。
- 新增 `uninstall.cmd`，删除本项目安装目录，以及两个技能目录中指向该安装的 `video-montage` 连接；不会删除其他同名技能入口。
- 新增 `package.cmd`。压缩包输出到 `release/`，默认名称为 `video-montage-v260928.zip`，包内顶层文件夹为 `video-montage-v260928`；打包排除任务结果、缓存、Git 数据和已有发布包。
- 移除包级 `.manifests/`、`runtime-lock.json`、`PACKAGE_MANIFEST.json` 及部署报告产物；运行时改用固定模块路径和关键文件检查。
- 新任务的安装状态、发布回执和运行时证据格式统一使用 `video-montage` / `v260928`。剪辑任务自身的素材来源 SHA-256、语义审核和成片质检证据继续保留。

### 升级说明

- 安装后重启 Codex，只使用 `video-montage` 技能。
- 旧 V9/V20 任务证据不自动迁移，已有任务须在新版中重新生成。
- 覆盖安装会删除 `%USERPROFILE%\video-montage` 内的全部内容；不要把个人任务文件放在该目录中。
