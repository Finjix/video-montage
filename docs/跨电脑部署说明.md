# video-montage v260928 安装

1. 在 64 位 Windows 上完整解压项目，双击 `install.cmd`。安装器只使用包内的 Python 3.13.15、FFmpeg、FFprobe 和 Whisper 模型，不通过网络下载依赖。
2. 安装器先检查随包运行环境，在临时副本运行回归和控制器预检；通过后清空 `%USERPROFILE%\video-montage`，清理旧版 `%USERPROFILE%\CodexMontageFF\20.2.5`，并安装新副本。目标目录中的个人文件也会被清除。
3. 安装器在 `%CODEX_HOME%\skills`（未设置时为 `%USERPROFILE%\.codex\skills`）和 `%USERPROFILE%\.agents\skills` 注册一个 `video-montage` 目录连接，并移除指向本项目旧安装的三个技能入口。
4. 完成后彻底退出并重新打开 Codex。新对话中使用 `video-montage`。

`install.cmd -PreflightOnly` 只检查源包，不复制或清理安装目录。检查结果只打印在终端；安装过程不生成 `.manifests/`、`artifacts/` 或部署报告。旧 V9/V20 任务证据不迁移，需用新版重新生成。

剪辑仍按源帧号执行；只有秒数的剪辑计划会被拒绝。语义审核、帧计划门禁、FFmpeg 控制器及编码后的独立质检都是交付条件。
