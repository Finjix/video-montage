# video-montage v260928

在 Codex 中使用 `video-montage` 技能。它从 `components/executor/scripts/three_suite_ff.py` 进入，由语义模块制定和审核帧计划，帧渲染器剪出预成片，FFmpeg 控制器编码并复检最终视频。

新任务和返修都须按执行器的 `preflight → init → semantic-run → semantic-complete → controller-preflight → controller-finalize → controller-validate → complete` 顺序执行。剪辑任务的工作单、来源追溯、语义审核、帧计划和成片质检回执保存在任务目录中。

生产裁切只接受 `source_in_frame`、`speech_end_frame`、`source_out_frame_exclusive` 与源帧率。只有秒数的计划会失败。来源素材及派生素材须绑定原片 SHA-256 和原始帧区间；用户判坏的区间不能靠改名或新候选 ID 绕过。候选首词需与预期台词强制对齐，切点两侧要检查画面和 PCM；独立审核与成片后复检不能省略。

实际首镜头视觉族决定片头重复度。默认成片为 H.264/AAC、1440×2560、60 fps，不额外加背景音乐、字幕或叠加元素。具体门禁和任务合同见 [语义流程](../skill/video-montage/semantic-workflow.md) 与 [控制器流程](../skill/video-montage/controller-workflow.md)。

安装包不输出 `.manifests/`、`artifacts/` 或部署报告。任务证据仍保留 SHA-256 绑定和完成回执。
