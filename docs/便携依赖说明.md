# 便携依赖

本套件在 64 位 Windows 上使用 `dependencies/python/python.exe`。随包包含 Python 3.13.15、对应模块、Visual C++ DLL、FFmpeg 9.0.2、FFprobe、完整 `faster-whisper-large-v3-turbo` 模型和可选的 CUDA 推理 DLL。运行和安装不调用系统 Python，也不使用 pip 或 winget 下载依赖。

主要模块包括 faster-whisper 1.2.1、CTranslate2 4.8.2、PyAV 18.1.0、NumPy 2.5.3、Pillow 12.3.0、OpenCV 5.0.0.93 和 ONNX Runtime 1.30.0。GPU 推理仍需要兼容的 NVIDIA 驱动；无法使用 CUDA 时，ASR 可回退 CPU。

`dependencies/python/` 存放解释器和模块，`dependencies/ffmpeg/` 存放 FFmpeg 与 FFprobe，`dependencies/models/` 存放模型，`dependencies/cuda/` 存放 CUDA DLL。用 `dependencies\python\python.exe tools\verify_runtime.py` 检查运行依赖；不会生成包级哈希清单。依赖版本见[依赖版本](依赖版本.md)。
